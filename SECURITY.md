# Segurança

## Reportando uma vulnerabilidade

**Não abra uma issue pública** para reportar vulnerabilidades.

Use o reporte privado do GitHub: aba **Security** deste repositório → **Report a vulnerability**.
O relato fica visível apenas para os mantenedores até a correção ser publicada.

Inclua, se possível:

- a linguagem e a versão do SDK afetadas;
- os passos para reproduzir;
- o impacto esperado (por exemplo, exposição de credenciais ou de token).

## Versões suportadas

Correções de segurança são publicadas na versão mais recente de cada SDK.

## Credenciais

Nunca inclua app key, usuário, senha ou tokens reais em issues, pull requests ou exemplos. Se uma
credencial for exposta, gere uma nova app key no sistema Ileva (*Configurações > Integrações >
API Integração*) e troque a senha do usuário.
